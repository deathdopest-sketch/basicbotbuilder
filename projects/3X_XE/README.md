# 3X_XE Bot

**Created by D****l "Death" N****n**

A Twitter bot that posts dark humor jokes and positivity content.

## Quick Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file with Twitter API keys:
```env
TWITTER_BEARER_TOKEN=your_token
TWITTER_APP_KEY=your_key
TWITTER_APP_SECRET=your_secret
TWITTER_ACCESS_TOKEN=your_token
TWITTER_ACCESS_TOKEN_SECRET=your_secret
```

3. Run the bot:
```bash
npm start
```

## Commands

- `npm start` - Start automated posting
- `npm run test` - Test connection
- `node bot.js --dark` - Post dark humor
- `node bot.js --positive` - Post positivity
- `node bot.js --stats` - Show stats

- 🤡 Dark humor jokes
