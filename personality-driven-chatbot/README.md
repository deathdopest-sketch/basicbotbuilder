# Personality-Driven Chatbot Framework

> Transform sophisticated AI technology into something anyone can use to create emotionally intelligent chatbots.

## What This Solves

Creating chatbots with advanced personality, emotional intelligence, and relationship tracking previously required expert programming knowledge. This framework democratizes that technology through simple configuration files and an interactive setup wizard.

**Before:** Months of programming to create emotional AI  
**Now:** 5 minutes answering questions about personality

## Quick Start

```bash
# 1. Install Node.js from nodejs.org (if you don't have it)
# 2. Download this project
# 3. Open terminal in the project folder
# 4. Run these commands:

npm install
npm run setup
npm run create
```

Answer simple questions about your bot's personality, and you'll have a sophisticated AI companion running in minutes.

## Features That Were Previously Expert-Only

- **Emotional Intelligence** - Automatically detects sadness, happiness, anger, fear and responds appropriately
- **Relationship Memory** - Remembers every user and builds deeper connections over time
- **Dynamic Personality** - Configurable traits that shape every response your bot gives
- **Social Awareness** - Understands group dynamics and conversation context
- **Permission Systems** - Sophisticated user management and escalation handling
- **Music Integration** - Responds to music discussions and can manage playlists
- **No Coding Required** - Everything configured through simple questions
