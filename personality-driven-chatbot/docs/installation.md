# Installation Guide

## Quick Start

1. **Download the framework**
2. **Install Node.js** from nodejs.org (if you don't have it)
3. **Open terminal** in the project folder
4. **Run setup commands:**

```bash
npm install
npm run setup
npm run create
npm start
```

## What Each Command Does

- `npm install` - Downloads required dependencies
- `npm run setup` - Creates data folders
- `npm run create` - Builds your bot's personality
- `npm start` - Launches your bot

## Requirements

- Node.js 14 or higher
- A bot account on your chat platform
- 5 minutes to answer personality questions

Your sophisticated AI companion will be ready in minutes!
